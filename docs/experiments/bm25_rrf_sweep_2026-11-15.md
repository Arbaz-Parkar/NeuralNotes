# BM25 and RRF parameter sweep

**Date:** 2026-11-15  
**Dataset:** `dpr-pilot-v0.11`, dev split, 56 paired queries  
**Workspace:** fixed-size (`11111111-1111-4111-8111-111111111111`)  
**Reference:** BM25 `k1=1.5`, `b=0.75`; hybrid RRF constant `60`  
**Comparison:** paired bootstrap, 2,000 resamples, seed 0, 95% intervals; metrics at `k=10`.

All runs used the development split. The held-out test split was not used to select parameters.

## Decision and limits

The sweep does not justify changing the current BM25 or RRF defaults. It covered one workspace and a modest development sample, so these results are exploratory rather than universal parameter recommendations. No test-split tuning was performed.
